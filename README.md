**Fruit Image Classification Android App**

A simple Android application for image classification using a TensorFlow Lite (.tflite) model.
The app can classify fruit images using either:
  Camera Capture
  Gallery Image Upload

**Features**
TensorFlow Lite image classification
Upload image from gallery
Capture image using camera
Displays predicted label with confidence score
Lightweight and easy to understand

**Model Information**
This project uses a custom TensorFlow Lite model:
model_unquant.tflite
Input Type: FLOAT32
Classes:Apple, Pineapple, Watermelon, Banana

**App Usage**
**Option 1: Upload from Gallery**
  Click Upload from Gallery
  Select an image
  View prediction result
**Option 2: Capture from Camera**
  Click Capture from Camera
  Allow camera permission
  Capture image
  View prediction result
